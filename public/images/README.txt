PHOTO FOLDERS  (full guide: HOW_TO_EDIT.md)
site/        big page pictures: hero.jpg promo.jpg feature.jpg about.jpg enquiry.jpg
categories/  one picture per category, named after the category id: fish-food.jpg
products/    one folder per category; photo named after the product: premium-tropical-flakes.jpg
Use lowercase names, no spaces, .jpg/.png/.webp, ~800px wide.
